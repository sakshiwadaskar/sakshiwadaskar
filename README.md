## Featured Projects

### 📊 [CapitalMirror — AI-Driven Financial Intelligence Platform](https://github.com/sakshiwadaskar/CapitalMirror-AI-Analytics)
Full-stack analytics platform that turns a raw P&L (CSV, PDF, or pasted text) into a 0–100 business health score in under 60 seconds. Claude Sonnet parses inconsistent, real-world financial documents into structured metrics; Claude Haiku generates plain-English rationale; a weighted scoring engine benchmarks the result against 10 industries. Interactive sliders let users re-run the score against live "what-if" assumptions with zero added latency.  
🔗 [Live demo](https://biz-health-dashboard.vercel.app/) · `Python` `FastAPI` `Claude Sonnet & Haiku` `React 19` `TypeScript` `Tailwind CSS` `Recharts` `Railway` `Vercel`

### 🏥 [Health Advisor Bot — Conversational Wellness Agent](https://github.com/sakshiwadaskar/health-advisor-bot)
Retrieval-augmented chatbot that answers general wellness questions (sleep, nutrition, exercise, stress, hydration) grounded strictly in a curated knowledge base — no hallucinated medical advice. Built a full RAG pipeline with LangChain over a Chroma vector store, served through FastAPI, and containerized with Docker for one-step deployment.  
🔗 [Live demo](https://health-advisor-bot.onrender.com/) · `Python` `FastAPI` `LangChain` `ChromaDB` `Gemma` `Docker`

### 🌍 [EcoEngage — Community Engagement Web App](https://eco-engage-web-application.vercel.app/)
Full-stack social platform for climate-focused community engagement. React/Redux frontend, Node.js RESTful APIs, OAuth 2.0 authentication, deployed on Vercel with MongoDB.  
`TypeScript` `React` `Node.js` `MongoDB` `Vercel`

### 🏨 Bahmni Health Management System
Open-source hospital management system. Contributed Java Spring modules with DynamoDB integration for patient record workflows.  
`Java Spring` `DynamoDB`
